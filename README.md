# inzaish-collection-

> **Inzaish Collection** — Luxury Pakistani Fashion E-Commerce Experience.

An artisanal fashion e-commerce storefront for Inzaish Collection, crafted with high-polish editorial aesthetics, Three.js interactive textile viewer, responsive mega-menus, curated unstitched & ready-to-wear collections, and a complete shopping experience.

## ✨ Features
- **Editorial Brand Direction:** Warm ivory/cream palettes, antique bronze accents, and luxury typography.
- **Responsive Header & Mega-Menu:** Dual-gender (Women & Men) navigation, deep categories (Unstitched, Ready-to-Wear, Festive & Formal).
- **Interactive Three.js Canvas:** Real-time 3D textile shader and fabric inspection.
- **Cart & Wishlist:** Persistent local storage shopping cart with drawer preview and real-time badge counters.
- **Cash on Delivery (COD) Checkout:** Tailored checkout flow for the Pakistani retail market with order consignment tracking.
- **Mobile First:** Slide-in drawer navigation with accordion controls and touch-optimized layout.

## 🛠️ Tech Stack
- **Frontend:** Vanilla JavaScript (ES Modules), HTML5, Vanilla CSS
- **3D Graphics:** Three.js (WebGL)
- **Tooling:** Vite, Rollup

## 🚀 Getting Started
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
